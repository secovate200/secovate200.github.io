## CREATE 구문
- 데이터베이스 생성

``` sql
CREATE DATABASE [DB_NAME];

```

- 테이블 생성

```SQL
CREATE TABLE [NAME] ([COLUMN_NAME] [DATA_TYPE]);
```

### 예제 

```sql
mysql> CREATE DATABASE SQL_BASIC;
mysql> USE SQL_BASIC
mysql> CREATE TABLE MEMBER(seq int, name char(20), email char(50));

mysql> show tables;
+---------------------+
| Tables_in_SQL_BASIC |
+---------------------+
| MEMBER              |
+---------------------+


mysql> desc MEMBER;
+-------+----------+------+-----+---------+-------+
| Field | Type     | Null | Key | Default | Extra |
+-------+----------+------+-----+---------+-------+
| seq   | int      | YES  |     | NULL    |       |
| name  | char(20) | YES  |     | NULL    |       |
| email | char(50) | YES  |     | NULL    |       |
+-------+----------+------+-----+---------+-------+

```

## INSERT 구문
- 데이터 삽입

```sql
INSERT INTO [TABLE_NAME](COLUMN1...) VALUES (DATA1...);

```

## SELECT 구문
- 데이터 조회

```SQL

SELECT [COLUMN_NAME] FROM [TABLE_NAME] WHERE [CONDITION];

```

## UPDATE 구문
- 데이터 수정

```SQL
UPDATE [TABLE_NAME] SET [COLUMN_NAME] = [DATA] WHERE [CONDITION];
```

## DELETE 구문
- 데이터 삭제

```SQL

DELETE FROM [TABLE_NAME] WHERE [CONDITION];

```

### 예제

```SQL
mysql> INSERT INTO MEMBER (seq,name,email) VALUES(1,'SECOVATE','SECOVATE200@123.COM');
Query OK, 1 row affected (0.014 sec)

mysql> SELECT * FROM MEMBER;
+------+----------+---------------------+
| seq  | name     | email               |
+------+----------+---------------------+
|    1 | SECOVATE | SECOVATE200@123.COM |
+------+----------+---------------------+
1 row in set (0.002 sec)

mysql> UPDATE MEMBER SET name ='123';
Query OK, 1 row affected (0.034 sec)

mysql> DELETE FROM MEMBER WHERE seq=1;
Query OK, 1 row affected (0.013 sec)
```
